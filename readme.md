# Tandem Tales Test Agent

A simple [Tandem Tales](https://sgware.github.io/tt) agent that can play any
world in either role. It instantly makes random choices and always agrees to
proposed actions.

## Download and Documentation

This library is written in pure Java and depends on the
[Tandem Tales Server Library](https://github.com/sgware/tt-server). You can
download a [pre-built JAR](build/jar) with with the dependencies included.

You can build this project from source using [Maven](https://maven.apache.org/):
```
git clone https://github.com/sgware/tt-test-agent.git
cd tt-test-agent
mvn clean install
```

The [JavaDoc API is here](https://sgware.github.io/tt-test-agent).
